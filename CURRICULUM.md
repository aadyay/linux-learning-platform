# Linux Learning Platform — Curriculum

## Platform Goal
A beginner-friendly interactive platform that teaches Linux from installation and basic concepts to practical command-line skills.

## 1. Getting Started — Linux Installation

### Lesson 1: Introduction to Linux
- What is Linux?
- What is an operating system?
- Linux vs Windows.
- What is Ubuntu?
- What are Linux distributions?

### Lesson 2: Choosing an Installation Method
- WSL (Windows Subsystem for Linux).
- VirtualBox and virtual machines.
- Dual boot.
- System requirements and preparation.
- Advantages and disadvantages of each method.

### Lesson 3: Installing Ubuntu
- Step-by-step WSL installation.
- Step-by-step VirtualBox installation.
- Ubuntu first-time setup.
- Creating a username and password.
- Opening the Linux terminal.

### Lesson 4: Your First Linux Commands
- Updating Ubuntu.
- Understanding the terminal prompt.
- Running your first commands.
- Common setup errors and troubleshooting.

## 2. Module 1 — Linux Fundamentals

### Lesson 1: Understanding the Linux Environment
- Linux architecture basics.
- Kernel, shell and user space.
- What is a command-line interface?

### Lesson 2: Understanding the Terminal
- Terminal vs shell.
- Command syntax.
- Options and arguments.
- Case sensitivity.

### Lesson 3: Exploring the System
Commands: `pwd`, `whoami`, `date`, `uname`, `history`

### Lesson 4: Navigation Basics
Commands: `ls`, `cd`, `clear`

## 3. Module 2 — Linux File System

### Lesson 1: Linux Directory Structure
- Root directory.
- Home directory.
- Important Linux directories.
- Understanding the directory hierarchy.

### Lesson 2: Paths and Navigation
- Absolute paths.
- Relative paths.
- Parent and current directories.
- Hidden files.

### Lesson 3: Creating and Managing Files
Commands: `mkdir`, `touch`, `cp`, `mv`, `rm`, `rmdir`

### Lesson 4: Reading and Searching Files
Commands: `cat`, `head`, `tail`, `find`, `echo`

## 4. Module 3 — Users and Permissions

### Lesson 1: Linux Users and Groups
- User accounts.
- Groups.
- Root user.
- User identification.

Commands: `whoami`, `id`, `groups`

### Lesson 2: Understanding File Permissions
- Read, write and execute.
- Owner, group and others.
- Understanding `rwx`.
- Reading permissions with `ls -l`.

### Lesson 3: Changing Permissions
- Symbolic permissions.
- Numeric permissions.
- Understanding values such as 755 and 644.

Commands: `chmod
